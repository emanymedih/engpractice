# WordMemo 1000 — English A2–B1

Интерактивный офлайн/PWA-тренажёр английского языка:

- 1000 частотных слов
- flash cards
- active recall / DREMO
- spaced repetition
- задания «вставь слово в предложение»
- русский перевод примеров
- библиотека слов
- библиотека английских времён и грамматический разбор предложений
- светлая / тёмная / системная тема
- адаптация под iPhone

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub, например `wordmemo`.
2. Загрузите **содержимое этой папки в корень репозитория**. Файл `index.html` должен лежать в корне.
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/ (root)` и нажмите `Save`.
6. Подождите, пока GitHub покажет опубликованный URL. Обычно это адрес вида:
   `https://USERNAME.github.io/wordmemo/`

## Установка на iPhone

1. Откройте опубликованный адрес именно в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой» (Add to Home Screen).
4. Подтвердите добавление.
5. После первого успешного открытия приложение кэширует основные файлы и может работать офлайн.

## Обновление

Замените файлы в репозитории новой сборкой. После публикации GitHub Pages новая версия станет доступна по тому же адресу.

> Учебный прогресс хранится локально в браузере устройства. Перед крупным обновлением рекомендуется сделать экспорт прогресса из настроек WordMemo.
